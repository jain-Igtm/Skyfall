# Skyfall visual asset sources

The texture assets in `public/assets/textures/` were generated specifically for Skyfall with OpenAI's built-in image generation workflow on 2026-08-03, then cropped and converted to mobile-sized WebP files.

## Station texture atlas

Prompt summary: a square 2-by-2, front-facing mobile game texture atlas containing grimy cold-gray station wall panels, dark ribbed steel floor plating, oxidized structural trim, and pale mineral-stained ceiling panels; old industrial science-fiction; flat diffuse light; clean quadrant boundaries; no text, objects, perspective, borders, watermark, or baked lighting.

Derived assets:

- `station-wall.webp`
- `station-floor.webp`
- `rusted-trim.webp`
- `station-ceiling.webp`

## Ghost ectoplasm

Prompt summary: a seamless cold blue-gray ectoplasmic material with vertical vapor wisps, fibrous smoke veins, pale filaments, void patches, and interference bands; grounded cosmic horror; flat texture information; no creature, face, silhouette, scene, text, border, watermark, or baked lighting.

Derived asset:

- `ghost-ectoplasm.webp`
